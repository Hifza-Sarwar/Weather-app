#  Weather App

A simple Python Weather App that uses the **OpenWeatherMap API** to fetch real-time weather information.

## Features

* Check weather for a single city
* Check weather for multiple cities (1–4)
* Displays:

  *  Temperature
  *  Weather condition
  *  Humidity
  *  Wind speed
* Handles invalid inputs and city names

## Technologies

* Python
* Requests
* OpenWeatherMap API

## Installation

Install the required library:

```bash
pip install requests
```

Run the application:

```bash
python weather.py
```

## API Key

Get your API key from [OpenWeatherMap](https://openweathermap.org/api) and add it to the code.
